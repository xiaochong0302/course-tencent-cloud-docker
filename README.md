### 项目介绍

为酷瓜云课堂企业版（腾讯云版） [ctc-pro-v2](https://gitee.com/koogua/ctc-pro-v2) 提供环境支持

### 安装指南

下载安装脚本

```
cd ~ && curl https://download.koogua.com/ctc-pro-v2/install.sh -o install.sh
```

根据实际情况修改配置

```
nano install.sh
```

执行安装，快慢取决于网络，当有错误或者超时请再次重试安装

```
bash install.sh
```
